# Private pilot activation requirements

Before a private pilot:

1. Pass App 6B-1 and 6B-2 pgTAP in the isolated Supabase runner.
2. Exercise actual private Storage signed URLs, deletion, expiry, and 30-day scheduler behavior.
3. Prove the deployed worker bundle contains and can run FFmpeg.
4. Obtain explicitly authorized clips for the other four rubrics and qualified human reference review.
5. Approve a recurring pilot cap separately; the one-time $5 authorization does not carry forward.
6. Configure only named pilot users, an atomic production ledger, cron authentication, and rollback monitoring.
7. Keep public and Expo flags off until a later explicit release decision.
