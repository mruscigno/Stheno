# Baseline

Before App 6C, Product 19 already supplied `member_review_state`, `monthly_reviews`, `monthly_recommendations`, private progress-photo tables/storage, the 28-day scheduler, web intake, deterministic review engine, Coach Decisions, and Fitness Memory. `/api/v1/progress` was read-only and the mobile Progress screen explicitly deferred monthly reviews and photos.

The principal gaps were no native bearer API for photos, no revisioned intake resume contract, non-transactional recommendation application, and no opt-in native monthly Progress UI.
