# App 5 entry gate

App 5 must not begin until all of the following are evidenced:

1. A debug or release Android build completes successfully.
2. The native app boots on physical Android hardware or an online emulator.
3. The full App 4 member walkthrough passes with screenshots and device logs.
4. A dedicated non-production STHENO Supabase environment is available.
5. Two synthetic users pass API, database, storage, and capability-claim isolation tests.
6. Verification and recovery links complete in the native app.
7. TalkBack, font scaling, keyboard, contrast, and narrow-screen checks pass.
8. iOS validation is completed on macOS/Xcode or is explicitly accepted as a separate outstanding release risk.
