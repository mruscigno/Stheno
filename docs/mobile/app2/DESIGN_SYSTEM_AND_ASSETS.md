# Design system and assets

The shell uses STHENO orange `#ff5a1f`, warm `#fffaf3`, ink `#171714`, restrained neutral borders, large editorial headings, 44–58px touch targets, and readable error/success surfaces.

The source vector is the existing canonical orange STHENO asset, copied without redesign. The app icon and splash PNGs are deterministic raster exports of that asset. The first screen uses the exact first question and options from the shared web assessment definition.

The narrow 500px Chromium preview was checked for wrapping, contrast, and touch sizing. Native 390px typography/rendering remains part of device QA.
