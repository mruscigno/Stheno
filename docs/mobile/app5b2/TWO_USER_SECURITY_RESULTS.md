# Two-user security results

Existing App 5/App 6C isolated pgTAP coverage remains the baseline. App 5B-2-specific two-user native testing was **not run** because neither required Android flow is reachable in the current lane.

No claim is made for native account-switch cache isolation, queued operations after logout, cross-user local rows, or App 6C device behavior. Those tests are mandatory after the single-job isolated runtime harness exists.
