# Monthly review parity

The 28-day engine still combines adherence, performance, recovery, weight/waist trends, and optional photo completeness conservatively. Photos never produce body-fat estimates or diagnoses. No-change remains a valid result. Low recovery supersedes a calorie cut, and pain blocks optimization.

New decisions include `MONTHLY_EVIDENCE_REVIEW`, methodology version, and evidence claim IDs. Application remains in `src/platform/server/monthly-reviews.ts`, where only explicitly accepted action IDs are applied.
