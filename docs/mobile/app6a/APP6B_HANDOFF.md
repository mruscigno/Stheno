# App 6B handoff

Use `src/modules/methodology/form-rubrics.ts` as the reviewed rubric contract. Before enabling any media flow, App 6B must define consent, retention/deletion, access isolation, upload limits, malware/content validation, human-review workflow, unsupported-view handling, model/version auditability, false-confidence controls, and an explicit non-diagnostic user experience.

Do not infer pain, injury, body composition, identity, mood, or medical status from video. Native device/runtime validation is still required in the later gate.
