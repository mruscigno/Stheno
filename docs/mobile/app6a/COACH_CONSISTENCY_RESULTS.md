# Coach consistency results

The existing web and `/api/v1` mobile Coach routes share `src/app/api/coach/route.ts`. The route now supplies the versioned methodology context alongside authoritative persisted training and nutrition facts. Safety and out-of-domain routing still occur before generation. Plan changes still route through deterministic, confirmation-required proposals.

Tests cover policy linkage, prompt boundaries, pain blocking, temporary travel scope, out-of-domain handling, and answer-quality checks. Raw conversations and private context are not added to analytics.
