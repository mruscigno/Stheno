# App 5B handoff

App 5B may integrate the backend protocol after CI is green. It must persist one UUID per user intent, retain base revision and exact normalized content across retries, process canonical server results, refresh on stale revision, and never invent client revisions. It should queue operations in creation order while allowing the server to resolve delayed retries deterministically. Native UI expansion remains blocked until the real data-backed Android Assessment → Blueprint → Account → Program walkthrough passes.
